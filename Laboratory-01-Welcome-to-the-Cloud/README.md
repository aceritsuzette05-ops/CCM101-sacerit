# Mission 1: Welcome to the Cloud

## Mission Overview

This mission introduced me to the Linux environment and basic cloud computing tasks using KillerCoda. I also learned how to organize and document my work using GitHub.

## Objectives

* Access and use a Linux environment through KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Create and organize files and directories.
* Create and maintain a GitHub repository.
* Document technical work using Markdown.

## Activities Performed

I accessed the Ubuntu Linux Playground using KillerCoda. I created a new Linux user with sudo access and logged in to the account. I checked the username, working directory, hostname, Linux distribution, kernel version, CPU information, memory, and disk space. I also created folders and Markdown files and prepared my GitHub Cloud Computing portfolio.

## Linux Commands Used

* whoami – checks the current username.
* pwd – shows the current working directory.
* hostname – shows the hostname.
* cat /etc/os-release – checks the Linux distribution.
* uname -r – shows the kernel version.
* lscpu – displays CPU information.
* free -h – displays memory information.
* df -h – displays disk space information.
* mkdir – creates directories.
* nano – creates and edits files.

## Skills Learned

Through this activity, I learned the basics of using Linux commands, managing files and folders, checking system information, creating Markdown files, and organizing my work in a GitHub repository.
