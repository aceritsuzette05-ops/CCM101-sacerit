# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform from Microsoft that provides services for computing, storage, networking, databases, security, artificial intelligence, and application development.

## Global Infrastructure

Azure operates through regions and datacenters around the world. Many Azure regions also provide Availability Zones to improve resilience and availability.

## Cloud Management Console

The Azure Portal is a web-based console used to create, manage, monitor, and configure Azure resources.

## Four Core Services

### 1. Azure Virtual Machines
Azure Virtual Machines provide virtualized computing resources in the cloud.

### 2. Azure Blob Storage
Azure Blob Storage is used to store large amounts of unstructured data.

### 3. Azure Virtual Network
Azure Virtual Network provides networking for Azure resources.

### 4. Microsoft Entra ID
Microsoft Entra ID provides identity and access management.

## Three Advantages

1. Strong integration with Microsoft technologies.
2. Global cloud infrastructure.
3. Wide range of enterprise services.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows-based workloads, databases, application development, hybrid cloud environments, and artificial intelligence.
