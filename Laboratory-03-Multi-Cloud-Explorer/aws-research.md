# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform that provides a wide range of computing, storage, networking, database, security, and other cloud services.

## Global Infrastructure

AWS operates through Regions and Availability Zones around the world. Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. AWS recommends selecting regions based on factors such as user location, services available, and requirements. 

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources.

## Four Core Services

### 1. Amazon EC2
Amazon EC2 provides resizable computing capacity through virtual servers.

### 2. Amazon S3
Amazon S3 is an object storage service used to store and retrieve data.

### 3. Amazon VPC
Amazon VPC provides networking capabilities for AWS resources.

### 4. AWS IAM
AWS IAM manages access to AWS resources and controls permissions.

## Three Advantages

1. Wide range of cloud services.
2. Global infrastructure.
3. Flexible and scalable resources.

## Typical Enterprise Use Cases

AWS can be used for web applications, data storage, enterprise applications, backup and disaster recovery, and large-scale computing workloads.
